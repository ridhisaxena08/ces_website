# 🎓 CES Website

A modern, responsive, and interactive website developed for the **Chandrawati Education Society (CES)** to provide information about the **Dual Degree Program**, enabling students to pursue their degree alongside a **Data Science degree from IIT Madras**.

The website serves as a digital platform where students can learn about the program, explore benefits, understand the admission process, and get in touch with the institution.

---

## 🌟 Live Demo

🔗 https://ces-website-tau.vercel.app

## 📖 Project Overview

The CES Website was developed to simplify access to information regarding the Dual Degree Program offered through Chandrawati Education Society. The platform provides detailed information about eligibility, program structure, benefits, admission guidance, and contact details.

The website is designed with a modern user interface and optimized performance to ensure a seamless experience across all devices.
